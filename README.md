# Forma Praxis

Marketing website for Forma Praxis, built as a lightweight Next.js landing page aligned to the brand direction in the `forma-praxis-branding` repository.

## Stack

- Next.js 14
- React 18
- TypeScript
- CSS variables for the pastel industrial brand system

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Production build

```bash
npm run build
npm run start
```

## Brand direction reflected

- Pastel industrial palette
- Editorial serif + technical sans/mono pairing
- Clear homepage narrative for services, process, and contact
- Discovery-first messaging without invented client proof points
